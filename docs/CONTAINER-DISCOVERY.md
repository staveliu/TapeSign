# 钱包容器选择

容器入口位于产品顶部，签约与公证共用同一选择。除了钱包列表，也可手动输入完整 ID，接受 `4.2.204` 或 `4.2.204.tape`（后缀不区分大小写）；点击“核验并使用”或按 Enter。手动输入无需等待自动枚举结束，旧枚举结果失效，但仍核验容器与当前持有人。关闭弹窗或钱包账户变化会取消旧核验，迟到的响应不会覆盖当前选择。

“选择我的容器”查询公开合约中当前钱包直接持有的已开通容器，不是钱包提供统一的 TapeOut 容器选择 RPC。

实现位于 src/containers.js 与 src/container-picker.js。读取工厂 cpuCount/cpuAt、处理器 nextId/ownerOf，再用 opener.isOpened 过滤。两条链使用当前状态批量读取，避免首次扫描全链转移历史。

单次每链最多检查 2,000 个电路，每 RPC 最多 128 个子调用；可继续查更早容器。部分失败或未扫描完成会提示，不能因此断言无其他容器，也不枚举托管平台内部账户。

候选通过两独立 RPC 一致性读取；每批固定近期共同区块并复查哈希，长扫描更新快照，列表并非全钱包同一时刻的完整证明。选择与签署前再次核验代码、绑定、持有人。

钱包账户变化使旧候选失效；连接、查询、选择只读，不发交易。界面用短 ID，例如 1.2.204（X Layer）和 1.204（BSC），已签文档保留规范 .tape 后缀。
